# Overall Plan – ws-dottie 1.3.1 + ws-dottie-mcp (Two Stages)

### Stage 1 – Extend ws-dottie to Export Derived JSON OpenAPI (v1.3.1)

Goal: Make `ws-dottie` publish OpenAPI specs as JSON via npm, so other tools (like `ws-dottie-mcp`) can consume them without filesystem assumptions.

#### 1. Add JSON generation to the docs pipeline

1. Inspect the existing OpenAPI generation script in `ws-dottie`:

   - `scripts/generate-docs/generate-openapi.ts` – already produces YAML under `docs/generated/openapi/*.yaml`.

2. Create a small script (or extend the existing one) to generate **JSON files** alongside YAML:

   - Read each YAML spec from `docs/generated/openapi/*.yaml`.
   - Convert the parsed object to JSON and write to a new output folder, e.g. `dist/openapi/*.json` or `docs/generated/openapi-json/*.json`.
   - Use `const` arrow functions for helpers (e.g., a `const convertYamlToJson = (…) => { … }`).

3. Update docs/build scripts so that JSON generation runs whenever OpenAPI YAML is generated:

   - Option A: Incorporate JSON emission directly into `generate-openapi.ts`.
   - Option B: Add a dedicated `scripts/generate-docs/generate-openapi-json.ts` and call it from the existing `docs:generate` script.

#### 2. Expose JSON specs via package exports

1. Decide on a stable public subpath, e.g. `"./openapi/wsf-vessels.json"`.
2. Update `package.json` in `ws-dottie` to include named exports for the JSON specs, for at least the ferry APIs:
```json
{
  "exports": {
    ".": {
      "types": "./dist/index.d.ts",
      "import": "./dist/index.mjs",
      "require": "./dist/index.js"
    },
    "./openapi/wsf-vessels.json": "./dist/openapi/wsf-vessels.json",
    "./openapi/wsf-terminals.json": "./dist/openapi/wsf-terminals.json",
    "./openapi/wsf-schedule.json": "./dist/openapi/wsf-schedule.json",
    "./openapi/wsf-fares.json": "./dist/openapi/wsf-fares.json"
  }
}
```

3. Ensure that these JSON files are included in the published package:

   - Verify `files` or `.npmignore` configuration so `dist/openapi/*.json` is shipped.
   - Confirm that main runtime entrypoints do not import these JSON specs, to avoid unnecessary bundle impact.

#### 3. Verify JSON exports and bump version to 1.3.1

1. Build and generate docs:

   - Run existing docs generation commands (e.g., `npm run docs:openapi` and the new JSON step).
   - Confirm that `dist/openapi/*.json` (or chosen path) contains valid JSON (e.g., via a quick Node read & parse).

2. Validate exports using a local test script or a temporary test project:

   - Install the local `ws-dottie` build as a dependency.
   - Import the JSON spec via the new path:
```ts

  console.log(wsfVessels.info?.title);

logTitle();
```


3. Update `CHANGELOG.md` and bump version to `1.3.1` in `package.json`, describing:

   - "Add exported OpenAPI JSON specs for ferry APIs under ./openapi/*.json".

4. Publish `ws-dottie@1.3.1` once tests pass.

### Stage 2 – Implement ws-dottie-mcp (Local Ferries-only MCP Server)

Goal: Create a standalone `ws-dottie-mcp` package that consumes `ws-dottie` (including its JSON OpenAPI specs) via npm, and exposes ferries-only MCP tools over stdio.

#### 4. Bootstrap the ws-dottie-mcp project

1. Create a new project folder, e.g. `../ws-dottie-mcp` (sibling to `ws-dottie`).
2. Initialize a TypeScript ESM project:

   - `package.json` with:
     - `"type": "module"`.
     - Scripts such as `dev`, `build`, `start` using `ts-node`/`tsx` or `tsc`.
   - `tsconfig.json` targeting Node 18+ / Bun, with `strict: true` and ESM module resolution.

3. Install dependencies:

   - Runtime: `@modelcontextprotocol/sdk`, `ws-dottie@1.3.1`, `zod`.
   - Dev: `typescript`, `tsx` or `ts-node`, `@types/node`.

4. Create the source layout:

   - `src/server.ts`
   - `src/config.ts`
   - `src/wsdottieClient.ts`
   - `src/openapi/ferries.ts`
   - `src/tools/ferries/` – EndpointGroup tools
   - `src/tools/docs/` – docs tools

All new functions should be declared as `const` arrow functions (e.g., `const main = async () => { … }`) to keep a functional style.

```ts
// src/openapi/ferries.ts (helpers)
interface OperationDetails {
  operationId: string;
  summary?: string;
  tag?: string;
}

export const getOperationsForTag = (doc: OpenAPIDoc, tagName: string): OperationDetails[] => {
  const paths = doc.paths ?? {};

  return Object.entries(paths).flatMap(([_, methods]) =>
    Object.values(methods ?? {}).flatMap((op: any) => {
      const tags: string[] = op?.tags ?? [];
      return tags.includes(tagName)
        ? [{ operationId: op.operationId, summary: op.summary, tag: tagName }]
        : [];
    })
  );
};
```

2. Implement `ferries_vessel_locations` tool in `src/tools/ferries/vesselLocationsTool.ts`:
```ts
// src/tools/ferries/vesselLocationsTool.ts
import type { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import type { FetchOptions, ToolError } from "../types.js";
import { ferriesClient } from "../../wsdottieClient.js";

export type VesselLocationsArgs =
  | {
      operation: "list_all";
      params?: {};
      options?: FetchOptions;
    }
  | {
      operation: "by_vessel_id";
      params: { VesselID: number };
      options?: FetchOptions;
    };

const toFetchOptions = (options?: FetchOptions) => ({
  fetchMode: options?.fetchMode ?? "native",
  validate: options?.validate ?? false,
} as const);

export const registerVesselLocationsTool = (server: McpServer): void => {
  server.tool("ferries_vessel_locations", {
    description: "Query real-time vessel locations and status for WSF fleet.",
    inputSchema: {
      type: "object",
      properties: {
        operation: { type: "string", enum: ["list_all", "by_vessel_id"] },
        params: { type: "object", additionalProperties: true },
        options: {
          type: "object",
          properties: {
            validate: { type: "boolean" },
            fetchMode: { type: "string", enum: ["native", "jsonp"] },
          },
          additionalProperties: false,
        },
      },
      required: ["operation"],
      additionalProperties: false,
    },
    handler: async (input: VesselLocationsArgs): Promise<any | ToolError> => {
      const { operation, params, options } = input;
      const fetchOptions = toFetchOptions(options);

      if (operation === "list_all") {
        try {
          return await ferriesClient.fetchVesselLocations({ params: {}, ...fetchOptions });
        } catch (err) {
          return { error: "Failed to fetch all vessel locations", details: String(err) };
        }
      }

      if (operation === "by_vessel_id") {
        const vesselId = params?.VesselID;
        if (typeof vesselId !== "number") {
          return { error: "VesselID must be a number" };
        }
        try {
          return await ferriesClient.fetchVesselLocationsByVesselId({
            params: { VesselID: vesselId },
            ...fetchOptions,
          });
        } catch (err) {
          return { error: "Failed to fetch vessel by id", details: String(err) };
        }
      }

      return { error: `Unsupported operation: ${String(operation)}` };
    },
  });
};
```

```ts
// src/tools/docs/ferriesGroupDocsTool.ts
import type { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { wsfVesselsDoc, wsfFaresDoc, wsfScheduleDoc, wsfTerminalsDoc } from "../../openapi/ferries.js";
import type { OpenAPIDoc } from "../../openapi/ferries.js";

const findTag = (doc: OpenAPIDoc, tagName: string) =>
  (doc.tags ?? []).find((t: any) => t.name === tagName) ?? null;

const ferriesDocs = [wsfVesselsDoc, wsfFaresDoc, wsfScheduleDoc, wsfTerminalsDoc] as const;

export const registerFerriesGroupDocsTool = (server: McpServer): void => {
  server.tool("get_ferries_endpoint_group_docs", {
    description: "Get documentation for a ferry EndpointGroup by name.",
    inputSchema: {
      type: "object",
      properties: { groupName: { type: "string" } },
      required: ["groupName"],
      additionalProperties: false,
    },
    handler: async ({ groupName }: { groupName: string }) => {
      const tag = ferriesDocs
        .map((doc) => findTag(doc, groupName))
        .find((t) => t != null);

      if (!tag) return { error: `Unknown groupName: ${groupName}` };

      return {
        name: tag.name,
        summary: tag.description ?? "",
        cacheStrategy: (tag as any)["x-cacheStrategy"] ?? undefined,
        useCases: (tag as any)["x-useCases"] ?? undefined,
        updateFrequency: (tag as any)["x-updateFrequency"] ?? undefined,
      };
    },
  });
};
```

```ts
import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";

import { registerVesselLocationsTool } from "./tools/ferries/vesselLocationsTool.js";
import { registerFerriesGroupDocsTool } from "./tools/docs/ferriesGroupDocsTool.js";

  registerVesselLocationsTool(server);
  registerFerriesGroupDocsTool(server);
  // register other tools here

  const transport = new StdioServerTransport();

  process.exit(1);
});
```
